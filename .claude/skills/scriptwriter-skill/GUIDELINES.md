# Scriptwriter Skill - Writing Guidelines

This document contains detailed screenwriting guidance, including the scene format specification, character description best practices, and beat distribution recommendations.

---

## Scene Format Specification

### Standard Scene Heading

```markdown
## Scene {X} - {INT./EXT.} {Location} - {Time}

{Scene-establishing description - 2-3 sentences, visual}

{Character action and dialogue}
```

**Example**:

```markdown
## Scene 5 - INT. Subway Car - Night

The car is dim; white fluorescent lights flicker on and off. A few discarded newspapers lie scattered across the empty seats.

EMMA (25, waist-length silver hair, violet eyes, wearing a dark red coat) sits by the window and opens an old leather-bound notebook.
The glow of dense handwritten symbols and a six-pointed star pattern lights her face.

Suddenly, all the lights go out.
```

### Scene Type Labels

- **INT.** = Interior
- **EXT.** = Exterior
- **INT./EXT.** = The scene moves between interior and exterior (a car, a doorway)

### Time Labels

- Specific time: morning, noon, afternoon, dusk, night, late night
- Relative time: continuous, same time, later, the next day

### Every Scene Must Turn

A scene is a unit in which something changes. A scene where nothing changes is an incident, not a scene, and it will not yield a beat.

**The Four Emotions check**: the lead enters the scene in one of **mad, glad, sad, scared** and leaves it in another. The shift may be small, but it must exist.

**The Mamet check** (if you cannot answer all three, the scene is not dramatic):

1. Who wants what?
2. What happens if they do not get it?
3. Why now?

**Scene and Sequel** (Swain): write scenes as **Goal → Conflict → Disaster** and follow them with a sequel of **Reaction → Dilemma → Decision**. The decision becomes the goal of the next scene. A scene without a disaster ending stalls; a story without sequels feels like meaningless action. Shorter sequels mean faster pace.

**Public and private objective**: every scene is a power grab. Each character has a public objective (what they say they want) and a private one (what they are hiding, consciously or not). Subtext lives in the gap.

**Scene procedure**:

1. Name the protagonist's wound, fear, visible goal, and where this scene sits in the arc.
2. State what the character wants in this scene. If pursuing it neither moves toward nor blocks the story goal, cut the scene.
3. Decide the actions they take to get it.
4. Write the dialogue on the nose first (characters announce what they want).
5. Rewrite so they get the same thing across without saying it.

Setbacks and failure create suspense; success and good news do not. Prefer scenes that leave the character worse off than they entered.

## Character First Appearance

**Must include**:

1. Name (or a descriptor if unnamed, e.g. MYSTERIOUS FIGURE)
2. Age range
3. Key appearance features (hair, clothing, signature items)

### Examples

```markdown
MARCUS (50s, short gray hair, navy blue suit with a red tie) pushes the door open and enters.

LILY (16, short black hair with purple streaks, ripped jeans and a band T-shirt) leans against the wall.

MYSTERIOUS FIGURE (gender unknown, full-length black cloak, face hidden by a mask, only a silver cross necklace visible) stands in the shadows.
```

### Body-First Design

Silhouette, mass, and posture tell the story before costume does. Choose them on purpose:

- **Shape language**: angular forms read as strength or threat; rounded forms read as gentleness.
- **Mass and posture**: a hulking upper body with a small head, or a belly-forward slouch, says more than a list of clothes.
- **Story overrides function**: a reluctant blacksmith may be lanky and badly equipped. Design against type when the story needs it.
- **No cliché descriptions**: draw from people you have seen, not from stock types.

### Canonical Description

The appearance description established on first appearance should remain consistent in all later scenes:

**First time**:

```
EMMA (25, waist-length silver hair, violet eyes, dark red coat)
```

**Afterwards**:

```
Emma's long silver hair blows in the wind, her dark red coat wrapped tightly around her.
Her violet eyes stare into the distance.
```

Full detail on first appearance, then simplify: later scenes repeat only the key identifiers.

## Character Spine

Before writing scenes, define the protagonist's spine. Every beat traces back to it.

| Element | Question | Example |
|---|---|---|
| **The Lie** | What false belief does the character hold about themselves or the world? | "I can only rely on myself." |
| **The Want** (Outer Goal) | What visible, physical goal do they pursue? | Retrieve the stolen diary. |
| **The Need** (Inner Need) | What must they accept to be whole? Usually the truth that refutes the Lie. | Accept help. |
| **The Ghost** (Prior Wound) | What past event created the Lie and the defensive flaw? | Abandoned by a mentor. |
| **The Stakes** | What do they lose if the Want fails? | The diary is destroyed; her sister's memory with it. |

**Want vs. Need**: the story ends when the Want and the Need converge. A character who gets the Want without the Need is a tragedy.

**The 4-Goal Rule**: the Outer Goal is one of **Win, Stop, Escape, Retrieve**. A visible physical finish line forces a physical, filmable climax. An internal goal alone cannot be storyboarded.

**The Active Hero**: the inciting event pushes the protagonist into a dilemma; the choice they make in that dilemma defines the Outer Goal; every obstacle afterwards links back to that choice. A lead to whom things merely happen is boring.

**Antagonist**: give them a reason, traits opposite to the protagonist's, and enough strength that the protagonist looks unable to win. Each time the protagonist acts, the antagonist's reaction makes things worse.

**Conflict on three layers**: Global (vs. world, society, nature), Local (vs. people close enough to care), Inner (vs. the Lie). Opposing views are only drama once they collide over a shared goal.

## Action Description Best Practices

### Use Present Tense, Active Voice

✅ **Correct**:

```
Emma rushes to the door. She grabs the handle and shoves the door open.
```

❌ **Wrong**:

```
Emma ran to the door and it was opened.
```

### Visual First

❌ **Abstract description**:

```
Emma feels confused and afraid.
```

✅ **Visual description**:

```
Emma's eyes widen, her fingers trembling as she turns the pages of the notebook. A bead of sweat slides down her forehead.
She takes a step back, her back against the wall, breathing hard.
```

### Specific, Not General

❌ **Vague**:

```
The room is a mess.
```

✅ **Specific**:

```
Books are scattered across the floor, a chair is overturned, the curtains half torn down. A coffee cup on the desk has tipped over, dark brown liquid spreading across the documents.
```

## Beat Distribution Guidance

### Distribution of 9 Beats Across the Three-Act Structure

Ensure the script contains **9 or more** clear key moments, one at each structural anchor. Anchors are percentages of the script's length, not equal page gaps.

**Act One (Setup / Ask, ~25%)**:

- **Beat 1** (Hook / Characteristic Moment, 0-10%): The protagonist shown acting in the Normal World. Not a static establishing shot; the scene still turns.
- **Beat 2** (Inciting Event, ~12%): The event that breaks the Normal World. It must involve the protagonist and move the story forward.
- **Beat 3** (First Plot Point, 20-25%): The protagonist's choice. It sets the Outer Goal (Win, Stop, Escape, Retrieve) and poses the dramatic question.

**Act Two (Confrontation / Acceptance, ~50%)**:

- **Beat 4** (First Attempt, 25-37%): The protagonist acts on the Want and gains tools; the Lie still steers them.
- **Beat 5** (First Pinch Point, ~37%): The antagonist's pressure lands. Things get worse.
- **Beat 6** (Midpoint, 50%): A moment of truth. The protagonist shifts from reacting to acting. Often a false victory.
- **Beat 7** (Third Plot Point / Low Point, ~75%): The greatest loss. The old self dies. The ultimate choice between Want and Need. This beat is the Act II/III turn.

**Act Three (Resolution / Answer, ~25%)**:

- **Beat 8** (Climax, ~90%): The Lie is rejected. The obligatory scene at the physical finish line.
- **Beat 9** (Resolution / New Normal, 98-100%): The thematic question is answered; the next dramatic question is opened.

### Example: Beat Distribution for a 30-Page Script

| Beat Number | Page | Type                | Example                                        |
| ----------- | ---- | ------------------- | ---------------------------------------------- |
| Beat 1      | p.2  | Hook                | Protagonist talks her way out of a fine, lying smoothly |
| Beat 2      | p.4  | Inciting Event      | Receives a mysterious package                  |
| Beat 3      | p.7  | First Plot Point    | Decides to retrieve the diary the package points to |
| Beat 4      | p.10 | First Attempt       | Finds the first clue, gains an unwanted ally   |
| Beat 5      | p.11 | First Pinch Point   | The organization burns down her apartment      |
| Beat 6      | p.15 | Midpoint            | Realizes the truth differs from what she imagined; goes on the offensive |
| Beat 7      | p.22 | Third Plot Point    | Betrayed by the ally, loses the diary          |
| Beat 8      | p.27 | Climax              | Final confrontation with the mastermind, trusting the ally again |
| Beat 9      | p.30 | Resolution          | Problem solved, but a new question is planted  |

### Beat Quality Standards

Each beat should be:

- **Visual** - Can be turned into a concrete image
- **A turn** - The emotional state at the end differs from the start
- **Anchored** - Sits at one of the nine structural anchors and does that anchor's job
- **Emotionally charged** - Carries a structural emotion (curiosity, anticipation, surprise) or a thematic one (sympathy, identification, empathy)
- **Independently identifiable** - Can be extracted as a standalone moment

## Series Continuity Management

### Key Points When Reviewing Previous Episodes

**Analysis checklist**:

- [ ] Main characters and their development arcs
- [ ] Established world-building and rules
- [ ] Unresolved plot threads
- [ ] Changes in character relationships
- [ ] Visual style and atmospheric tone
- [ ] Key scenes and locations already used

### First Appearance vs Later Appearances

**In the first episode**:

```
EMMA (25, waist-length silver hair, violet eyes, wearing a dark red coat) walks into the room.
```

**In the second episode and after**:

```
Emma walks into the room, her long silver hair and dark red coat still striking in the dim light.
```

**Key**: Keep the appearance keywords consistent, but there is no need to repeat the age and every detail in full each time.

### World-Building Consistency

**Established rules must be obeyed**:

If ep01 established that "magic fails during the day", ep02 cannot feature a "magic duel at noon".

**Extendable but not contradictory**:

- ✅ ep02 introduces a new type of magic (extension)
- ❌ ep02 changes the established rules of magic (contradiction)

**Sanderson's laws** for any magic, technology, or power system:

1. The story may solve problems with the system only as far as the audience understands it. Unexplained power that saves the day is a cheat.
2. Limitations are more interesting than powers. What the system cannot do forces characters to be clever.
3. Expand what already exists before adding something new.

**Transformations** (new powers, forms, upgrades) must pass three tests: they cost something, they reveal something about the character, and they are irreversible or leave a permanent scar. Raising the power ceiling every episode makes earlier stakes meaningless; grow sideways (new uses, tactics) rather than upward.

## Three-Act Structure in Detail

### Act One (Setup / Ask, ~25%)

**Goal**: Establish the Normal World, introduce the protagonist in action, break the world, and force a choice

**Elements included**:

1. **Hook / Characteristic Moment** - The protagonist doing something that shows who they are and what Lie they live by
2. **Normal World** - The foundation. The better it is built, the more the audience believes what happens in Act Three
3. **Inciting Event** (~12%) - Breaks the Normal World; involves the protagonist; moves the story forward
4. **First Plot Point** (20-25%) - The protagonist chooses. The choice sets the Outer Goal and poses the dramatic question. The audience should know what the character wants and what happens if they fail

Pose the dramatic question between one sixth and one third of the way in. Delay conflict too long and the audience leaves; start it too early and you must sustain that pace.

**Example**:

```
Scenes 1-2: Emma's everyday work (librarian); she bends a rule to help a stranger (hook)
Scene 3: Discovers a hidden message in an ancient book (inciting event)
Scene 5: Decides to retrieve the diary before the organization does (first plot point: Retrieve)
```

### Act Two (Confrontation / Acceptance, ~50%)

**Goal**: The protagonist commits and persists. Obstacles escalate, the Lie fails them, the truth starts to show

**Elements included**:

1. **First attempt** - The protagonist acts on the Want and gains tools; moves closer to the Want and farther from the Need
2. **First Pinch Point** (~37%) - The antagonist's force is shown directly; the protagonist is worse off
3. **Midpoint** (50%) - A moment of truth. The protagonist stops reacting and starts acting. A false victory works well here
4. **Second Pinch Point** (~62%) - Pressure renewed; the Lie and the truth pull in opposite directions
5. **Third Plot Point** (~75%) - The low point. The old self dies. The protagonist must choose between the Want and the Need. This is the Act II/III turn

Every protagonist action should trigger an antagonist reaction that makes things worse, at the worst possible time.

**Example**:

```
Scenes 6-9: Investigates clues, encounters a mysterious organization
Scene 10: The organization burns down her apartment (first pinch point)
Scene 11: Discovers the truth is more complicated than imagined; goes on the offensive (midpoint)
Scenes 12-14: Hunted; loses the diary to the ally's betrayal (third plot point)
```

### Act Three (Resolution / Answer, ~25%)

**Goal**: Test the new truth, reach the climax, show the New Normal

**Elements included**:

1. **Regrouping** - The protagonist acts on the Need, not the Lie, for the first time. Strip away tools, escape routes, and allies so they face the climax self-reliant
2. **Climax** (~90%) - The obligatory scene at the physical finish line. The Lie is rejected for good. Highest suspense sits here, not before
3. **Resolution** (last ~2%) - The thematic question answered; the New Normal shown, not told
4. **Next question** - A new dramatic question planted for the series

**Example**:

```
Scene 15: Emma accepts the ally's help instead of going alone (regrouping)
Scenes 16-17: Final confrontation with the organization's leader (climax)
Scene 18: Crisis resolved, but a question for the next episode is planted
```

### Where the Story Starts and Ends (MICE)

Decide which kind of story this episode is and keep the ending in the same kind:

- **Milieu**: begins when the protagonist enters a strange place; ends when they leave or choose to stay
- **Idea**: begins when a question is posed; ends when the truth is revealed
- **Character**: begins when the status quo becomes unbearable; ends when the character changes or fails to
- **Event**: begins when the world's order is disrupted; ends when order is restored or lost

A mystery resolved by an explosion instead of an answer is a story that started as Idea and ended as Event.

### Logline (planning only, not output)

> When [inciting event] happens, [protagonist] decides to [action] against [antagonist].

If the logline cannot be written, the Outer Goal or the antagonist is missing.

## Dialogue Writing Techniques

### Character Voice Consistency

Each character should have a distinctive way of speaking:

**Marcus (50s, old-fashioned gentleman)**:

```
"Young man, this is a good deal more complicated than you think. I'd think twice before doing anything."
```

**Lily (16, rebellious teenager)**:

```
"Come on, Marcus. Your antique rulebook doesn't work here."
```

### Avoid Meaningless Filler

❌ **Redundant**:

```
"Um, I think, maybe, perhaps, we should, you know, give it a try..."
```

✅ **Concise**:

```
"Let's try."
```

### Subtext

Do not say everything outright; give the dialogue layers:

❌ **On the nose**:

```
"I don't trust you, because you betrayed me before."
```

✅ **Subtext**:

```
"That's what you said last time." (implies distrust and past betrayal)
```

Write the on-the-nose version first, then rewrite it as subtext (see Scene procedure above).

### Distinct Voices

A line is the scene's stimulus passed through the character's background and motive toward the scene's ending. If every character sounds the same, the character step is being skipped: the line reacts to the stimulus directly. Write the whole script in one voice first if it helps, then do a pass that individualizes each character's lines.

## Output Checklist

After finishing, check:

- [ ] Every scene has a clear scene heading (INT./EXT., location, time)
- [ ] Every scene turns (emotional state at exit differs from entry) and passes the Mamet check
- [ ] Characters have a full appearance description on first appearance
- [ ] Action descriptions use present tense, active voice
- [ ] Protagonist has a Lie, Want, Need, Ghost, and Stakes; the Want is Win, Stop, Escape, or Retrieve
- [ ] Contains at least 9 clear beats, one at each structural anchor
- [ ] Three-act structure is complete (Hook, Inciting Event, First Plot Point, First Attempt, First Pinch Point, Midpoint, Third Plot Point, Climax, Resolution)
- [ ] Dialogue matches each character's personality
- [ ] Sufficient visual description, avoiding abstract psychological description
- [ ] If a continuing episode, character appearance is consistent with previous episodes
- [ ] World-building has no contradictions and any power system obeys Sanderson's laws
- [ ] No frontmatter metadata or template instructions
